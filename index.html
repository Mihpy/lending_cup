01 / О проекте

Контроль без лишнего шума

Интерфейс помогает быстро оценить качество телеметрии и понять, что происходит с отдельными подсистемами аппарата.

«ИнтроСат» принимает телеметрию учебного спутника от эмулятора или от реального конструктора по COM-порту, проверяет пакеты, показывает состояние модулей и ведёт журнал сеанса.

Состояния разделены на норму, внимание, аварию и отсутствие данных. Рядом с оценкой отображается причина: отказ одного датчика не должен автоматически делать аварийным весь спутник.

02 / Функциональность

Инструменты оператора

Основные разделы пульта и задачи, которые они решают.

01 — OVERVIEW

Обзор

Питание, группы параметров, поток данных и карта целостности полей.

02 — TELEMETRY

Телеметрия

Все 16 полей пакета: значение, физическая величина и достоверность.

03 — ANALYSIS

Анализ

Статистика, поиск выбросов и экспорт результатов в CSV.

04 — ATTITUDE

Ориентация

Трёхмерная модель спутника, углы, угловые скорости и магнитное поле.

05 — COMMANDS

Команды

Проверка аргументов, очередь передачи и состояние канала.

06 — LOG

Журнал

События, пакеты, отчёт о сеансе и воспроизведение записи от ×0,25 до ×16.

07 — SETTINGS

Настройки

Адрес источника, пороги состояний, тема и положение приборов.

03 / Быстрый старт

Запуск с эмулятором

Для демонстрации приёма телеметрии можно использовать открытый эмулятор.

Подготовьте эмулятор

Получите mcc-hack/data-emulator. Требуется Python 3.10 или новее.

python emulator.py

Выберите набор данных

Укажите файл телеметрии, например 01_normal_flight.csv, в интерфейсе эмулятора.

Откройте пульт

Адрес источника http://127.0.0.1:8765/telemetry приложение подхватит автоматически.

Для проверки сценария со сбоями откройте 02_sensor_faults.csv в разделе «Журнал» через «Открыть лог из файла» и установите скорость ×16.

04 / Desktop

Десктопная сборка

Версия «ИнтроСат ЦУП» на Electron собирается из папки electron.

Для сборки требуется Node.js. Команды выполняются из корня проекта:

npm install
npm start
npm run build:win
npm run build:mac
npm run build:linux
